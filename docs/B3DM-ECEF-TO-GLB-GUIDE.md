# B3DM 转 GLB 完整指南 - PCA 自动贴地对齐

## 📋 概述

`convert-b3dm-ECEF-to-glb.js` 是一个完整的 B3DM 到 GLB 转换脚本，专注于：

- ✅ **PCA 自动贴地对齐**：通过主成分分析自动检测模型平面方向
- ✅ **保留 ECEF 坐标**：保留原始 RTC_CENTER 用于真实世界定位
- ✅ **地理位置信息**：自动提取并保存经纬度信息
- ✅ **完整元数据**：包含 DualCanvasViewer 需要的所有信息

## 🎯 核心特性

### 1. PCA 自动贴地对齐
- 主成分分析计算模型主要方向
- 自动检测模型平面法线
- 旋转模型使平面与地面平行（Y 轴正方向）

### 2. ECEF 坐标保留
- 保留原始 RTC_CENTER（ECEF 坐标）
- DualCanvasViewer 使用此值识别大坐标模型
- 支持真实世界模式切换

### 3. 地理位置提取
- 从 RTC_CENTER 计算经纬度
- 保存海拔高度信息
- 用于 Cesium 相机定位

### 4. 几何数据处理
- 应用 PCA 旋转到所有顶点
- 重新计算法线方向
- 更新 accessor.min/max 边界框

## 🚀 使用方法

### 基本用法

```bash
# 转换当前目录下的 B3DM 文件
node convert-b3dm-ECEF-to-glb.js L16_10302.b3dm

# 指定完整路径
node convert-b3dm-ECEF-to-glb.js /path/to/L15_12345.b3dm

# 指定输出文件名
node convert-b3dm-ECEF-to-glb.js input.b3dm output.glb
```

### 输出文件

默认输出文件名格式：`<原文件名>_ECEF_to_ThreeJS.glb`

例如：
- `L16_10302.b3dm` → `L16_10302_ECEF_to_ThreeJS.glb`
- `JiAn1_merge.b3dm` → `JiAn1_merge_ECEF_to_ThreeJS.glb`

## 🐛 故障排除

### 问题：模型未贴地（Y 最小值不在 0 附近）

**原因**：PCA 分析结果不准确

**解决方案**：
- 检查采样顶点数量
- 验证模型几何是否完整
- 可能需要手动调整旋转角度

### 问题：模型倾斜

**原因**：主方向识别错误

**解决方案**：
- 检查特征值分布
- 验证模型是否是平面建筑
- 可能需要手动指定旋转角度

### 问题：法线方向错误

**原因**：法线旋转矩阵与顶点不一致

**解决方案**：
- 确认使用相同的旋转矩阵
- 检查法线归一化

### 问题：在 DualCanvasViewer 中无法识别为大坐标模型

**原因**：rtcCenter 未正确保存

**解决方案**：
- 检查 B3DM 文件是否包含 RTC_CENTER
- 验证元数据是否正确添加
- 查看控制台日志

## 💡 技术说明

### 为什么只使用 PCA 对齐？

1. **保持原始坐标系**：B3DM 中的顶点已经是局部坐标
2. **避免双重转换**：ECEF 转换会改变模型方向，破坏 PCA 分析
3. **简化流程**：一步到位，直接贴地对齐
4. **兼容性**：与 DualCanvasViewer 的处理逻辑一致

### PCA 原理

主成分分析（Principal Component Analysis）通过计算顶点坐标的协方差矩阵，找到模型的主要延伸方向：

- **特征值最大** = 最大延伸方向（如建筑物长度）
- **特征值中等** = 中等延伸方向（如建筑物宽度）
- **特征值最小** = 最小延伸方向 = **平面法线**

通过旋转让最小特征值对应的特征向量指向 Y 轴正方向，即可实现贴地对齐。
